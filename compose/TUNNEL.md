# Testing on external devices through a Cloudflare tunnel

Sometimes you need to use your local development environment from another device:
a phone, a tablet or another computer. Many features, such
as PWA installation, push notifications and passkeys, only work on a secure
(HTTPS or localhost) origin. You can expose your local development environment over
HTTPS through a [Cloudflare quick tunnel](https://try.cloudflare.com/), which requires
no Cloudflare account. This allows you to test against your local development
environment on a device that is not even on the same network.

## Setup

Install `cloudflared` (e.g. `brew install cloudflared`).

## Usage

```bash
mise tunnel              # Start a tunnel (same as: mise tunnel start)
mise tunnel status       # Show whether the tunnel is running and which URL is in use
mise tunnel stop         # Stop the tunnel and go back to localhost
```

`mise tunnel` starts `cloudflared` in the background, stores its random
`https://<words>.trycloudflare.com` address as `TUNNEL_URL` in `mise.local.toml`
and recreates `dummy-idp` and restarts `apigw`, `frontend` and `service` if they are
running, because they read the address only at startup. If the environment is not
running yet, just run `mise start` afterwards. Open the printed URL on your device.

## What changes

When `TUNNEL_URL` is set, the whole app uses it instead of localhost: the Suomi.fi
SAML flow (the dummy IdP is served at `/idp` on the same origin), the WebAuthn
relying party, links generated by the service, and Vite's allowed hosts and HMR.
`http://localhost:<frontend port>` still serves the frontend, but logging in there
does not work while the tunnel is active.

## Things to know

- Every new tunnel gets a new address, so restarting the tunnel (or rebooting your
  machine) means restarting the services again. `mise start` warns if `TUNNEL_URL`
  points to a tunnel that is no longer running. `mise stop` and `mise restart` leave
  the tunnel running.
- Anyone who knows the address can reach your development environment, including
  the dev login pages. Stop the tunnel when you no longer need it.
